# BAWIM

Ten projekt to proste i konkretne materiały o CSRF. Porusza tematyke ochrony przed tym zagrożeniem a także jego konsekwencje. Zaczynamy od krótkiej prezentacji, która wyłuszcza najważniejsze pojęcia bez zbędnego lania wody, a zaraz po niej wchodzi strona demonstracyjna, na której na żywo widać, jak taki atak właściwie działa. Dla utrwalenia wiedzy przygotowaliśmy szybki quiz i 3 proste zadania praktyczne.
